# Deadline Countdown

Плагин для Visual Studio Code, который показывает обратный отсчёт до дедлайна прямо в строке состояния редактора.

**Автор:** Кузичкин Данил, группа М3118

## Описание

Deadline Countdown помогает не забыть о сроке сдачи работы. Задаёшь название и дату дедлайна, и внизу окна VS Code появляется таймер, который обновляется каждую секунду. По мере приближения срока меняется смайлик и цвет полоски прогресса, а когда время выходит, плагин спрашивает, успел ли ты сдать работу.

## Возможности

- **Таймер в строке состояния.** Показывает, сколько осталось до дедлайна, с точностью до секунды: `Лаба 3: 6 д 04:12:37`.
- **Смайлик-настроение.** Меняется по мере приближения срока:
  - 😎 больше 3 дней;
  - 🙂 от 1 до 3 дней;
  - 😰 меньше суток;
  - 😱🔥 меньше часа (смайлик мигает).
- **Цветная полоска прогресса** `▰▰▰▰▱▱▱▱▱▱`. Показывает, какая часть времени от момента установки дедлайна уже прошла, и плавно меняет цвет от зелёного через жёлтый к красному.
- **Предупреждения.** Уведомления, когда до дедлайна остаётся меньше суток и меньше часа.
- **Вопрос в конце срока.** Когда время выходит, плагин спрашивает «Ты успел сдать?» с кнопками «Успел» и «Не успел» и показывает результат: `Лаба 3: сдано!` или `Лаба 3: не успел`.
- **Досрочная сдача.** Команда «Я уже сделал» отмечает работу выполненной до дедлайна: `Лаба 3: сдано за 2 д 05:13:42 до дедлайна`.
- **Автоочистка.** Через час после ответа результат исчезает, и плагин готов к новому дедлайну.
- **Меню по клику.** Клик по таймеру открывает меню: «Я уже сделал», «Изменить дедлайн», «Убрать дедлайн».
- **Сохранение между запусками.** Дедлайн хранится в настройках VS Code и не пропадает после перезапуска редактора.

## Использование

1. Кликни по надписи `Дедлайн не задан` в левом нижнем углу окна или открой палитру команд (`Ctrl+Shift+P`) и выбери **Deadline: Задать дедлайн**.
2. Введи название дедлайна, например `Лаба 3`.
3. Введи дату в формате `ГГГГ-ММ-ДД ЧЧ:ММ`, например `2026-10-26 23:59`. Время можно не указывать, тогда дедлайн будет в 23:59 этого дня.

## Установка

```
git clone <>
cd deadline-countdown
npm install
npm run compile
```

Затем открой папку в VS Code и нажми `F5`. Откроется окно Extension Development Host с запущенным плагином.

## Технологии

- TypeScript
- VS Code Extension API: `StatusBarItem`, `commands`, `window.showInputBox`, `window.showQuickPick`, `workspace.getConfiguration`, `ExtensionContext.globalState`
- esbuild для сборки
